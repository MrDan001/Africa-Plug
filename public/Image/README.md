# Africa Plug image library

Commit public image assets into the folders below. Their website paths match the repository path after removing `public`.

- `Store/` — Store banner and product artwork.
- `Hero/Home/` — homepage hero slide artwork.
- `Hero/Work-with-FK/` — Work With FK hero artwork.
- `Hero/Tap-in/` — T.A.P IN hero artwork.
- `Tap-in/` — opportunity/listing images.
- `Work-with-FK/` — Work With FK supporting images.
- `Blog/` — editorial and article covers.
- `General/` — shared site artwork.

Example: `public/Image/Store/cover.jpg` is served at `/Image/Store/cover.jpg`.

Existing assets under `public/images/` and `public/store/` remain supported; no existing paths or Blob assets are removed.
